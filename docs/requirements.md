# Financial Digital Twin Requirements

## 1. Financial Profile

The system shall maintain a financial profile for each user.

The profile may contain:

- Income
- Employment
- Monthly expenses
- Assets
- Liabilities
- Credit accounts
- Savings
- Financial goals

## 2. Transaction Management

Users shall be able to:

- Import transactions
- Categorise transactions
- View transaction history
- Search transactions
- Filter transactions
- Correct transaction categories

## 3. Financial Simulation

Users shall be able to create hypothetical financial scenarios.

A scenario must not modify the user's actual financial state.

Examples:

- Purchase a vehicle
- Move to another city
- Change salary
- Take on a loan
- Increase debt repayments
- Increase monthly savings
- Take a holiday

## 4. Forecasting

The system shall generate financial projections using historical
financial data and user-defined assumptions.

Forecasts shall include:

- Cash flow
- Savings
- Debt
- Emergency fund
- Net worth
